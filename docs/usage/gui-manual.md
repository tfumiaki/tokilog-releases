# Tokilog Desktop GUI 使い方マニュアル

Tokilog Desktop GUI は、ローカル保存を前提にした軽量な時間記録ツールの画面版です。

作業を始める・止める・切り替える、今日の記録を直す、過去を探す、といった日常操作を画面から行えます。記録は CLI (`tl`) と同じローカル DB に入るので、**どちらから記録しても同じデータ**です。

入手と起動は、利用環境ごとの Getting Started を先に読んでください。

- macOS: [getting-started-macos.md](./getting-started-macos.md)
- Windows: [getting-started-windows.md](./getting-started-windows.md)
- Linux (Ubuntu): [getting-started-linux.md](./getting-started-linux.md)

## DB の upgrade

初めて起動したときや、Tokilog を新しい版へ更新したあとは、DB の更新が必要なことがあります。そのときは起動画面に **[Set up database]**（初回）または **[Upgrade database]** が出ます。

- **押す前に、ほかの Tokilog（CLI を含む）を閉じてください。** 押すと、DB の写し（`tokilog.db.before-upgrade-<時刻>.bak`）を DB の隣に保存してから更新します
- 更新が終わると、再起動しなくてもそのまま使えるようになります
- **更新している間に Tokilog へ届いた通常の終了の要求は取り消し、理由を画面に出します。** ただし、強制終了や OS による終了は防げません。途中で終了すると、DB に「マイグレーションのロック」が残ったり、途中まで更新された DB が残ったりすることがあります
- 失敗したときは、原因と写しの場所が画面に出ます。同じボタンでやり直せます。途中まで更新された DB を自動で元へは戻しません
- 「マイグレーションのロックが残っています」と出たときは、**この画面を含むすべての Tokilog（ほかの PC・古い版を含む）を閉じ、更新が実行中でないことを確かめてから**、CLI で `tl db unlock-upgrade --force --confirm-no-upgrade-running` を実行します。CLI は Desktop とは別に導入が要ります（[Getting started](./README.md)）。CLI は、画面に出ているのと同じデータフォルダを使うようにしてください（`TOKILOG_DATA_DIR` で起動している場合は、CLI にも同じ値を指定します）。実行中の更新のロックを外すと、DB が途中の状態で残るおそれがあります

CLI の `tl upgrade` でも同じ更新ができます（[CLI マニュアル](./cli-manual.md)）。ただし、CLI の `tl upgrade` は写しを取りません。

## 画面の見取り図

上から順に 4 つの領域があります。

| 領域 | 役割 |
|---|---|
| **ヘッダ** | 検索・ヘルプ・設定の入口 |
| **Command Bar** | 1 行で操作を打つ場所（折りたためます） |
| **現在作業カード** | いま走っている作業。走っていないときは、次に始める下書き |
| **Today** | その日の記録の一覧 |

検索・設定・ヘルプは、**ヘッダのボタンで開く面**です。開くと本体の上に重なります。

## 作業を始める・止める・切り替える

### 始める

走っていないとき、現在作業カードに**下書きの欄**が出ています。作業の内容を書いて **[Start]** を押します。

### 止める

走っているとき、カードに **[Stop]** が出ています。

- **[Stop]** — いま止める
- **[Stop] の右の時計マーク** — **過去の時刻を指定して止める**（席を離れていた分を戻したいときなど）

### 切り替える

**[Switch]** を押すと、**古い作業を走らせたまま**、次の作業の下書きが開きます。内容を書いて確定すると、そこで入れ替わります。

**始める・止める・切り替えるは、キーボードからも行えます。** 割当はヘッダの **?**（ヘルプ）で確認してください。

## 作業情報の書き方

**1 行で書きます。** 書き方は CLI の `tl add` と同じです。

```text
打ち合わせ @tokilog #design
```

| 書くもの | 意味 |
|---|---|
| そのままの文字 | 作業の内容 |
| `@名前` | project |
| `#名前` | tag（いくつでも） |
| `--from 10:00` | 開始時刻 |

`@` や `#` を打つと**候補が出ます**。選べばそのまま入ります。

**時刻の書き方や省略の規則は CLI と同じ**なので、細かい話は [cli-manual.md](./cli-manual.md) の「作業情報の入力ルール」を参照してください。

## 走っている作業を直す

カードの**鉛筆マーク**から直せます。

- **内容と開始時刻** — 鉛筆を押すと欄になります
- **project** — project のチップを押すと選べます
- **tag** — **[+]** で足し、チップの **×** で外します
- **ノート** — 長めのメモを残せます。ノートがある行には印が付きます

## 今日の記録を見る・直す

Today の一覧に、その日の記録が時刻順に並びます。

| 行のボタン | できること |
|---|---|
| **鉛筆** | 内容・開始・終了・ノートをその場で直す |
| **▶** | **その作業でまた始める**（走っていれば切り替える） |
| **ごみ箱** | 削除する |
| **[+]** | tag を足す |

**空き時間（gap）の行**には **[+]** が出ます。押すと、その時間帯を埋める記録を作れます。

**手動で足す**ときは、Today の見出しにある **[+]** を押します。一覧の末尾に入力の行が出るので、そこに書いて確定します。

## 別の日を見る

Today の見出しの **‹ / ›** で前後の日へ移ります。**あいだの日付を直接打つ**こともできます。

**今日へ戻る**ボタンで、今日の表示に戻ります。今日を表示しているあいだは、日付が変わると自動で追従します。

## 過去を探す

ヘッダの**虫めがね**で検索の面が開きます。

**検索も 1 行で書きます。** 作業情報と同じ語彙に加えて、期間と件数を指定できます。

```text
打ち合わせ @tokilog --from 2026-09-01 --to 2026-09-30
```

結果の行からは、**その日を開く**か、**その作業で始める**かを選べます。

## 画面を広く使う

Today の見出しにある**広げるボタン**で、Command Bar と現在作業カードを畳み、一覧に高さを渡します。走っている作業は 1 行のバーで表示され、そこからも止められます。

## project と tag を整える

**設定（歯車）** の中にあります。

- **統合** — 使わなくなった名前を、残す名前へまとめます
- **一覧** — 「Projects and tags」を開くと、**本体を見ながら**全部の名前と件数を確認できます（**別の窓で開きます**）

## 自動エクスポート

**設定（歯車）** の中で、記録をファイルへ自動で書き出せます。書き出し先のフォルダと形式を選んで保存します。

## キーボードショートカット

**ヘッダの ? を押すと、いまの環境の割当が出ます。**

**この文書には一覧を載せていません。** 割当は OS によって違い、画面のほうは**実際に動いている割当をそのまま出す**ので、そちらが正確です。
